# Low Poly Underwater Pack (Free)
by reodesuxz

A free low poly underwater pack: coral, sea creatures, seaweed, shells and a sunken shipwreck set, ready for ocean levels, aquarium games and VR dives.

## Contents
- FBX/  - one .fbx per model (Unity, Unreal, Godot, Blender)
- GLB/  - one .glb per model (Godot, three.js, Babylon.js, web)
- OBJ/  - one .obj + .mtl per model
- Underwater_AllAssets.blend - every model in one Blender file (Blender 4.3+)

## Specs
- Total: 8993 triangles for all 30 models (60-716 tris each)
- Flat-shaded, simple shared materials (no textures needed)
- Real-world scale in metres, pivot at the base centre
